# Notification Sound Files

This folder contains notification sound files for the live chat system.

## Required Files

1. **notification.mp3** - Notification beep sound for new messages
2. **notification.ogg** - Fallback format for browsers that don't support MP3

## Adding Notification Sounds

You can download free notification sounds from:
- https://notificationsounds.com/
- https://freesound.org/
- https://mixkit.co/free-sound-effects/notification/

Recommended: A short (0.5-2 second) pleasant beep or chime sound.

## Usage

The sound will play when:
- Admin receives a new user message (in admin panel)
- User receives a new admin message (in chatbot)
- New call request is received (in admin panel)

## Sound Toggle

Admins can mute/unmute sounds using the sound toggle button in the Live Chat Admin panel.
