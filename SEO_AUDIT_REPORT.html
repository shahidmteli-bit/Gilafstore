1. Executive Summary

Gilaf Store has a solid SEO foundation with a dedicated 782-line SEO functions library, proper JSON-LD structured data for products, dynamic canonical URLs, and complete Open Graph / Twitter Card coverage. However, several critical issues undermine search engine visibility.

✓
Title & Meta Description: Dynamic, properly escaped, with intelligent fallbacks per product and page.
✓
Canonical URLs: Present on all pages. Product pages use slug-based canonical with override support.
✓
Product JSON-LD: Multi-variant Offers with real pricing, GTIN/EAN, AggregateRating (real reviews only).
✓
Open Graph + Twitter Cards: Complete coverage. Product pages get og:type=product with brand, availability, condition.
✓
Organization + WebSite Schema: Global JSON-LD on all pages via footer, including SearchAction for sitelinks.
✓
Product Sitemap: Dynamic PHP with image tags, 24h cache, slug-based URLs.
✗
www vs non-www Domain Split: Canonical uses www.gilafstore.com but ALL sitemaps use gilafstore.com. Google treats these as separate sites.
✗
Logo <h1> on Every Page: The header logo is wrapped in <h1>, giving every page 2+ <h1> tags. This is the single most impactful on-page SEO fix available.
!
No hreflang tags: Despite having a language detection system, no hreflang link elements exist in <head>.
!
Missing breadcrumb schema on shop and category pages (only product pages have BreadcrumbList JSON-LD).

8. Heading Hierarchy (<h1>) Audit

CRITICAL GLOBAL ISSUE: The site logo in includes/new-header.php (line 373) is wrapped in <h1>: 
<h1 style="color: #ffffff; ...">GILAF STORE</h1>
This renders on every single page, meaning every page with a content <h1> actually has 2 or more <h1> tags. Google's John Mueller has explicitly stated: "Multiple H1s are fine... but having a logo as H1 is not ideal."

Fix: Change logo <h1> to <span> or <div>. This is a single-line change with maximum SEO impact.

10. Hreflang / Internationalization

Status: NOT IMPLEMENTED

Zero <link rel="alternate" hreflang="..."> tags found in any production PHP file.

Context: The site includes a language_banner.php in the footer (suggesting language detection), and a GLOBAL_LANGUAGE_SYSTEM.md documentation file exists. However, no hreflang signals are sent to search engines.

Impact: If the site serves different content to users based on language/region preferences, Google cannot discover or index those alternate versions. This leads to:
  • Duplicate content issues if same page exists in multiple languages
  • Wrong language version appearing in search results for different markets

Impact: Google's crawler sees the sitemap URLs pointing to gilafstore.com but the pages themselves declare www.gilafstore.com as canonical. This creates a conflicting signal loop:
  • Crawl budget wasted crawling both versions
  • Link equity split between www and non-www
  • Potential indexation of wrong domain version
  • Rich results may fail validation if URL doesn't match canonical
Fix: Update ALL sitemap files to use https://www.gilafstore.com (matching canonical). OR set up 301 redirect from non-www to www at server level.
