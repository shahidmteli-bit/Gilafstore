3. Safe Redirect Optimization Implemented

3.2 Optimized Redirect Rules (AFTER)

# Force HTTPS + WWW (canonical: https://www.gilafstore.com) # Redirects all HTTP (www and non-www) and HTTPS non-www to HTTPS www in one step RewriteCond %{HTTPS} off [OR] RewriteCond %{HTTP_HOST} !^www\. [NC] RewriteRule ^(.*)$ https://www.gilafstore.com/$1 [L,R=301]

✅ Fix Logic Explained

  • %{HTTPS} off — Matches if request is HTTP (not HTTPS)
  • %{HTTP_HOST} !^www\. — Matches if host does NOT start with www
  • [OR] — Logical OR between conditions
  • Single rule handles all 4 URL variations in one step
